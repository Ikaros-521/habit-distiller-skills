# 开源公开项目双语文档预设 (Preset: Bilingual Docs)

## 准则说明
面向公开开源平台（如 GitHub）的项目，文档采用独立的双文件架构：主文件 `README.md` 默认为简体中文，另设独立的 `README_en.md` 英文文件，双方在文件顶栏互挂超链接跳转，兼顾国内上手与国际传播。

## 适配规则片段 (Rule Snippet)
```markdown
**开源双语文档**：针对开源至 GitHub 等公开平台的项目，文档采用双文件独立中英双语架构：主文件 README.md 默认为简体中文，另设独立的 README_en.md 英文文件，双方顶栏互挂超链接跳转。
```
