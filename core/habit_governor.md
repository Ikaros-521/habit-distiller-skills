# Habit Governor: 习惯轻量管理与存储规范 (KISS 版)

本文档定义了个人习惯的**本地存储、写前备份、极简管理与冲突仲裁**规则。

---

## 1. 存储设计：零侵入单一真相源

- **存储路径**：`~/.habit-distiller/habits.md`
- **零代码库污染**：习惯绝对只保存在用户本机用户目录下，严禁写入任何具体项目的代码仓库或 IDE 配置文件。
- **写前原子备份**：任何增删改之前，自动复制当前文件为 `~/.habit-distiller/habits.md.bak`，保障随时可后悔撤回。
- **规则总量精炼**：全量习惯建议维持在 **5~8 条核心法则**，崇尚极简有效，拒绝规则堆叠膨胀。

---

## 2. 极简管理指令集

| 用户口令 | AI 执行动作 |
| :--- | :--- |
| **“查看我的习惯”** / **“查看习惯清单”** | 读取 `~/.habit-distiller/habits.md`，输出一张清晰紧凑的清单表格。 |
| **“删除习惯 [名称/序号]”** | 写前备份后，精准剔除指定习惯，其余规则完好保留并确认。 |
| **“撤回刚才的习惯更新”** | 将 `habits.md.bak` 物理原子覆盖回 `habits.md`，向用户说明恢复成功。 |

---

## 3. 冲突处理原则 (人本裁决)

当新提炼的习惯与已有规则存在明显矛盾冲突时：
1. **严禁自作主张**：AI 不得私自覆盖或猜测；
2. **说明原因让用户选**：清清楚楚把【规则 A】和【规则 B】以及矛盾根因列出，让用户决定保留哪一个。

---

## 4. 运行性能准则

- **日常代码与轻量问答**：习惯在会话启动时常驻上下文中生效，**严禁在回答简单问题前主动调用工具读盘**，保证秒级响应零延迟；
- 仅在用户显式要求“查看”、“删除”、“撤回”或“提炼”习惯时，才调用文件工具操作磁盘。
