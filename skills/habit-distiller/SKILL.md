# Habit Distiller (用户协同契约守护与全景治理技能 v2.5)

本 Skill 是面向现代 AI IDE / Agent 体系的**用户协同契约守护、防碎片化治理与动态注入引擎**。

---

## 核心行为准则 (Runtime Behaviors)

### 行为一：日常运行、清单查询与一键撤回
1. **一键习惯清单查询 (List Habits)**：
   - 当用户发送“查看我的习惯”、“查看习惯清单”、“习惯状态”或“list habits”时：
   - 立即读取 `~/.habit-distiller/habits.md`，以 1 页精炼的**可视化计分卡表格**直接渲染呈现当前六维规则，并附带快捷指令提示。
2. **多套习惯档案无缝切换 (Multi-Profile Switcher)**：
   - 当用户发送“切换习惯 [名称]”、“使用 [名称] 档案”时：自动保存当前修改，并将 `profiles/<name>.md` 原子替换为活跃生效的 `habits.md`。
   - 当用户发送“查看习惯档案”时：列出 `~/.habit-distiller/profiles/` 下所有可用档案并高亮当前活跃项。
3. **单条习惯定向精准注销 (Targeted Habit Deletion)**：
   - 当用户发送“删除习惯 [名称/序号]”或“注销 [名称] 习惯”时：
   - 生成写前镜像 `habits.md.bak`，精准剔除目标条目，保持其余规则完好无损，并输出删除确认卡片。
4. **自然语言一键撤回 (Undo Protocol)**：
   - 当用户要求“撤回刚才的习惯更新”或“恢复上一版习惯”时：
   - 检查 `~/.habit-distiller/habits.md.bak` 并物理原子替换回 `habits.md`，立即向用户确认回滚完毕。
5. **意图自适应分级 (Adaptive Depth)**：
   - ⚡ **微任务**：走 Fast-Path 极速直通，秒级返回纯净答案，免除心跳与看板；
   - 🛡️ **重任务**：走 Deep-Path 深度防线，全量激活前瞻推演、步骤心跳与交付看板（通过看板表格必填项锚定自审，杜绝遗漏）。

---

### 行为二：提炼、知行合一自愈与防肥胖收敛
当用户触发“提炼对话习惯”或主动探针触发时：
1. **主观虚词反模糊与强制逃生 (Disambiguation & Force-Write)**：
   - 遇到抽象虚词（如“更艺术”、“更严谨”），AI 必须转译为可量化工程指标向用户反问澄清；
   - 若用户回复“强制写入”或坚持原话，AI 立即原样写入，绝不反复争辩。
2. **知行背离智能自愈提示 (Habit-Action Drift Arbitration)**：
   - 当检测到用户连续多次实际操作违背既有书面习惯时，AI 主动输出冲突仲裁卡，由用户选择：当前会话临时特例放行、修改书面契约、或注销该习惯。
3. **单域 1+3 浓缩熔断**：
   - 每个领域严格限制为“1 条核心纲领 + 最多 3 条边界指标”，拟增加第 4 条时强制浓缩合并，杜绝单域肥胖。
4. **手工编辑自愈保护 (Permissive Self-Healing)**：
   - 读取时若发现用户手写的非标准条目，绝对禁止丢弃；重新落盘时自动将其规范化吸纳至合适 Domain 插槽。
5. **长会话低噪音提炼输出 (Low-Noise Mode)**：
   - 提炼完成后，聊天主界面仅输出 3 行紧凑结论，详细治理 Diff 自动折叠至 `<details>` 面板。
