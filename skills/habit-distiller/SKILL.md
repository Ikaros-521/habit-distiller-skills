# Habit Distiller (零侵入全局伴生习惯守护与全景治理技能)

本 Skill 是面向现代 AI IDE / Agent 体系的**个人习惯守护、防碎片化治理与动态注入引擎**。

---

## 核心行为准则 (Runtime Behaviors)

### 行为一：日常会话中的习惯感知与冲突仲裁
1. **级联路径探测 (Cascade Resolution)**：
   依次尝试读取：`$HABIT_DISTILLER_PATH` -> `~/.habit-distiller/habits.md` -> `./.agents/habits.md`。
2. **规则冲突智能仲裁 (Conflict Arbitration)**：
   当检测到个人习惯与当前项目硬性规则（如 `CLAUDE.md`、`CONTRIBUTING.md`）发生冲突时，主动抛出选择：
   - `[1]` 仅当前会话临时遵从项目规范（单次豁免）；
   - `[2]` 调整个人习惯，增加项目规范优先例外；
   - `[3]` 坚持使用个人习惯。
3. **日常静默遵守六维准则**：
   - 🧠 **前瞻推演与盲区发散**：多想 1~2 步，推演潜在缺陷与生命周期盲区；
   - 🛡️ **缺陷连带清零**：关联确凿缺陷无破坏一并彻底修复；
   - 📡 **运行过程微反馈**：多步操作输出简明步骤心跳；
   - 📊 **双轨高可读看板**：终态总结采用结构化对比表呈现；
   - 🌐 **开源双语文档**：开源公开项目默认中英双语、中文置顶；
   - 🚫 **红线禁忌防线**：坚决不触碰 `[DOMAIN: FORBIDDEN]` 中的反模式与高危操作。

---

### 行为二：习惯生命周期治理与提炼 (Habit Governance)
当用户输入“提炼对话习惯”或**主动纠偏探针触发（同类纠偏 $\ge 2$ 次，默认开启）**时：
1. **写前原子备份**：写入前自动备份为 `habits.md.bak`；
2. **约束保真合并**：同类合并时必须 100% 保留量化参数与边界判定细节，严禁空洞化泛化；
3. **四态路由比对**：
   - 重复项拦截去重；
   - 演化项版本覆盖（更新时间戳）；
   - 同类项升维合并；
   - 新领域挂载六大插槽之一；
4. **差异审计报告 (Diff Report)** 提请用户确认后落盘。
