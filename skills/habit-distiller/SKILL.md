# Habit Distiller (用户协同契约守护与全景治理技能)

本 Skill 是面向现代 AI IDE / Agent 体系的**用户协同契约守护、防碎片化治理与动态注入引擎**。

---

## 核心行为准则 (Runtime Behaviors)

### 行为一：日常运行、冲突对比与一键撤回
1. **意图分级自适应 (Adaptive Depth)**：
   - ⚡ **微任务**（命令查验、短文本问答）：走 Fast-Path 极速直通，秒级返回纯净答案，免除心跳与看板；
   - 🛡️ **重任务**（代码改动、重构排查）：走 Deep-Path 深度防线，全量激活前瞻推演、步骤心跳与交付看板。
2. **结构化契约防漏自审 (Schema-Enforced Audit)**：
   - 深度任务交付看板中，必须通过 `| **习惯契约核验** | 🛡️ [连带清零/反馈贯穿] |` 字段物理锚定履约核验，杜绝注意力漂移遗漏。
3. **自然语言一键撤回 (Undo Protocol)**：
   - 当用户要求“撤回刚才的习惯更新”或“恢复上一版习惯”时：
   - 检查 `~/.habit-distiller/habits.md.bak` 并物理原子替换回 `habits.md`，立即向用户确认回滚完毕。
4. **子代理协同关系 (Subagents)**：
   - 默认不强制向子代理盲目注入习惯库；由主 Agent 在派生任务提示词中自然传达偏好，并由主 Agent 最终负责交付把关。
5. **规则冲突并排对比自选 (Conflict Resolution)**：
   - 遇个人习惯与项目规范互斥时，主动以并排表格列出冲突项，提供“项目优先 / 个人优先 / 智能折中”三选一决策。

---

### 行为二：提炼、手改自愈与低噪音呈现
当用户触发“提炼对话习惯”或主动探针触发时：
1. **手工编辑自愈保护 (Self-Healing)**：
   - 读取时若发现用户手写的非标准条目，绝对禁止丢弃；重新落盘时自动将其规范化吸纳至合适 Domain 插槽。
2. **防过拟合与敏感信息审查**：
   - 严禁将单次算法选择误判为习惯；检测到内部 IP/Token 时主动提示脱敏或保留。
3. **长会话低噪音提炼输出 (Low-Noise Mode)**：
   - 提炼完成后，聊天主界面仅输出 3 行紧凑结论，详细治理 Diff 自动折叠至 `<details>` 面板，绝不刷屏干扰代码主线。
