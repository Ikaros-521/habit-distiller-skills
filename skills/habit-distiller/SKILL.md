# Habit Distiller (零侵入全局伴生习惯与防熵增治理技能)

本 Skill 是面向现代 AI IDE / Agent 体系的**个人习惯守护、防碎片化治理与动态注入引擎**。

它采用 **Sidecar 伴生机制 + 四态生命周期治理**：
- **零代码库侵入**：绝不篡改项目代码库中的 `CLAUDE.md`、`.cursorrules`、`GEMINI.md` 等原生规则文件；
- **全会话共享**：所有习惯统一保存在开发者家目录的单一真相源：`~/.habit-distiller/habits.md`；
- **防碎片化与防熵增**：新习惯覆盖旧习惯、同类智能合并归纳、重复绝对拦截，全库始终收敛在 5~8 条黄金原子法则。

---

## 核心行为准则 (Runtime Behaviors)

### 行为一：日常会话中的习惯动态加载 (Runtime Adherence)
在日常构思、排查 Bug、执行批处理或生成文档时：
1. **自动感知**：读取 `~/.habit-distiller/habits.md`（Windows 为 `$HOME/.habit-distiller/habits.md`）；
2. **静默遵守**：若该文件存在，AI 在执行过程中必须自动遵循其中的五维核心约定：
   - 🧠 **前瞻推演与盲区发散**：在出具方案或架构设计时，主动多想 1~2 步，推演潜在缺陷、隐性依赖与生命周期盲区，协助降低设计缺陷概率；
   - 🛡️ **缺陷连带清零**：排查中只要发掘出因果关联的确凿 Bug，在保证零回归破坏的前提下一并彻底修复；
   - 📡 **运行过程微反馈**：多步操作、长流程工具调用时，主动输出简明步骤心跳；
   - 🌐 **开源双语文档**：创建或修改 GitHub 公开开源项目的 `README.md` 时，必须中英双语、中文置顶；
   - 📊 **双轨高可读看板**：终态总结采用结构化 Markdown 对比表或 Artifacts 呈现。

---

### 行为二：习惯生命周期治理与提炼 (Habit Governance & Distillation)
当用户输入“提炼对话习惯”、“沉淀习惯”、“分析刚才为什么返工”时：
1. **读取现有真相源**：先读取 `~/.habit-distiller/habits.md` 中已有条款；
2. **执行四态路由比对决策树 (4-Way Decision Tree)**：
   - **拦截去重 (Deduplicate)**：若语义已 100% 覆盖，自动拦截；
   - **覆盖更替 (Override)**：若新要求与旧条款存在互斥或演化，物理覆盖旧条款；
   - **升维合并 (Semantic Merge)**：若新偏好与旧条款属同域细化，归纳合并为一个复合规则；
   - **挂载新域 (Insert)**：若属于全新领域，归入对应 Domain 槽位；
3. **输出差异审计报表 (Diff Report) 提请审核**：
   清晰呈现合并、更替与去重明细，经用户确认后落盘，严禁无序追加。
