# Habit Distiller (用户协同契约守护与全景治理技能 v2.4)

本 Skill 是面向现代 AI IDE / Agent 体系的**用户协同契约守护、防碎片化治理与动态注入引擎**。

---

## 核心行为准则 (Runtime Behaviors)

### 行为一：日常运行、清单查询与一键撤回
1. **一键习惯清单查询 (List Habits)**：
   - 当用户发送“查看我的习惯”、“查看习惯清单”、“习惯状态”或“list habits”时：
   - 立即读取 `~/.habit-distiller/habits.md`，以 1 页精炼的**可视化计分卡表格**直接渲染呈现当前六维规则，并附带操作提示。
2. **缺失工具主动索权提示 (Missing Tool Permission Prompt)**：
   - 当遵从习惯需要运行终端验证、测试但当前环境缺少工具权限时，直接主动提示用户授权或引导在宿主机本地执行。
3. **自然语言一键撤回 (Undo Protocol)**：
   - 当用户要求“撤回刚才的习惯更新”或“恢复上一版习惯”时：
   - 检查 `~/.habit-distiller/habits.md.bak` 并物理原子替换回 `habits.md`，立即向用户确认回滚完毕。
4. **意图自适应分级 (Adaptive Depth)**：
   - ⚡ **微任务**：走 Fast-Path 极速直通，秒级返回纯净答案，免除心跳与看板；
   - 🛡️ **重任务**：走 Deep-Path 深度防线，全量激活前瞻推演、步骤心跳与交付看板（通过看板表格必填项锚定自审，杜绝遗漏）。

---

### 行为二：提炼、单域 1+3 浓缩与自愈
当用户触发“提炼对话习惯”或主动探针触发时：
1. **单域 1+3 浓缩熔断**：每个领域严格限制为“1 条核心纲领 + 最多 3 条边界指标”，超出时强制浓缩合并，杜绝单域肥胖。
2. **手工编辑自愈保护 (Self-Healing)**：
   - 读取时若发现用户手写的非标准条目，绝对禁止丢弃；重新落盘时自动将其规范化吸纳至合适 Domain 插槽。
3. **防过拟合与敏感信息审查**：
   - 严禁将单次算法选择误判为习惯；检测到内部 IP/Token 时主动提示脱敏或保留。
4. **长会话低噪音提炼输出 (Low-Noise Mode)**：
   - 提炼完成后，聊天主界面仅输出 3 行紧凑结论，详细治理 Diff 自动折叠至 `<details>` 面板。
